# Диаграммы сайта кафедры информационных технологий и электронного обучения

Учебный проект для задания по UML. Диаграммы написаны на PlantUML, программная модель классов — на Python.

## Содержание
- `diagrams/01_use_case.puml` — варианты использования.
- `diagrams/02_class.puml` — диаграмма классов.
- `diagrams/03_sequence.puml` — последовательность входа в личный кабинет.
- `diagrams/04_state.puml` — состояния учебной задачи.
- `diagrams/05_activity.puml` — деятельность при создании учебной задачи.
- `src/models.py` — пример Python-модели, соответствующей основным классам.
- `report.md` — предметная область, подход к работе и комментарии к диаграммам.

## Как сгенерировать диаграммы
1. Установить Java и расширение PlantUML для VS Code либо IntelliJ IDEA.
2. Открыть файл `.puml`.
3. Использовать команду PlantUML **Preview Current Diagram** (название может немного отличаться в зависимости от расширения).
4. Для экспорта изображения выбрать PNG или SVG в командах расширения.

Альтернативный вариант — воспользоваться онлайн-редактором PlantUML: https://www.plantuml.com/plantuml/
