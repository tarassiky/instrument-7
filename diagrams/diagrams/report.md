# Разработка UML-диаграмм сайта кафедры информационных технологий и технологического образования

## 1. Описание предметной области

Предметной областью является информационный сайт кафедры информационных технологий и технологического образования РГПУ им. А. И. Герцена. Сайт предназначен для предоставления актуальной информации о деятельности кафедры студентам, преподавателям, абитуриентам и другим посетителям.

Основными информационными разделами являются сведения о кафедре, новости, мероприятия, информация о преподавателях, образовательных программах, документы и контактные данные.

В рамках разработки предполагается совершенствование структуры и внешнего оформления сайта, повышение удобства навигации и упрощение поиска необходимой информации. Для актуализации содержимого предусматривается возможность управления страницами, новостями и мероприятиями через административную часть сайта.

## 2. Подход к выполнению задания

Для проектирования сайта использован язык визуального моделирования UML. Диаграммы подготовлены с помощью PlantUML, который позволяет описывать структуру и поведение информационной системы с использованием текстового кода.

В процессе выполнения задания разработаны пять диаграмм: вариантов использования, классов, последовательности, состояний и деятельности.

Диаграмма вариантов использования определяет основных пользователей сайта и доступные им функции. Диаграмма классов описывает структуру данных и взаимосвязи между сущностями. Диаграмма последовательности отражает взаимодействие посетителя, интерфейса, обработчика запросов и базы данных. Диаграмма состояний демонстрирует жизненный цикл новости. Диаграмма деятельности описывает процесс подготовки и публикации информационного материала.

## 3. Процесс создания диаграмм

Для создания диаграмм использовано расширение PlantUML в Visual Studio Code. Для каждой диаграммы подготовлен отдельный файл с расширением `.puml`. В файлах описаны элементы UML и связи между ними.

После подготовки кода диаграммы визуализируются средствами PlantUML. Полученные изображения можно использовать в отчёте и презентации. Исходные файлы сохраняются в репозитории вместе с программным кодом и пояснениями.

Для диаграммы классов дополнительно подготовлен пример реализации моделей на Python с использованием Django ORM. Данный код показывает, как основные сущности информационного сайта могут быть представлены в программном решении.

## 4. Результат работы

В результате сформирована проектная модель сайта кафедры, отражающая его основные функции, структуру данных и типовые сценарии работы. Разработанные диаграммы могут использоваться при проектировании интерфейса, организации хранения информации и реализации механизмов управления содержимым сайта.
